# ePayslip Prospect Pipeline

This repository contains the ePayslip prospect-management dashboard.

## Publish the site

After creating a pull request from Codex, open the repository in GitHub and connect it to your preferred static-site host (for example, Netlify or Vercel). The app is a static site and requires no build command.

## Run locally

```bash
npm run dev
```

Open `http://localhost:4173` while that command is running.
